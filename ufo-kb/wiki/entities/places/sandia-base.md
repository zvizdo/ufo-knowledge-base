# Sandia Base

> *Stub. Expand with operational history, AFSWP-era organizational structure, and additional UAP-related primary documentation as it enters the KB.*

US Army / DoD nuclear-weapons installation in Albuquerque, New Mexico, established in 1946. Headquarters of the [[afswp|Armed Forces Special Weapons Project (AFSWP)]] from its 1947 founding; co-located with the [[aec]] nuclear-weapons assembly operations that grew into [[sandia-national-laboratories]]. Absorbed into [[kirtland-afb]] in 1971.

## UAP Relevance

- **AFSWP Classified Documents Library File 333.5 ("Unidentified Flying Objects")** was maintained at Sandia Base from at least 1949 (renewal annotation 1952); released 2026 as [[dow-uap-d17-sandia-base-1948-1950]].
- Multiple 1948-1949 UAP sightings reported FROM Sandia Base in the 17th OSI District catalog (per [[dow-uap-d17-sandia-base-1948-1950]]); witnesses include AEC Security Agents, AESS Inspectors, Military Police.
- December 5, 1948 Sandia Base — AEC Security Agent observed green UAP (catalog entry #10)
- January 6, 1949 — Pfc Meredith J. Everitt witnesses diamond-shape over the Sandia Base airstrip Ordnance Area (NOTE 4 in D17).
- March 21, 1950 — 11-witness "flying wing" formation over Sandia Base / Kirtland (catalog #204).
