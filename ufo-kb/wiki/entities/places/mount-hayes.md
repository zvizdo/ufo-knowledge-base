# Mount Hayes

## Description

Mount Hayes is a peak in the eastern Alaska Range. In the context of the CIA/SRI [[stargate-program|Stargate]] [[remote-viewing]] program in **1973**, the psychic spy [[pat-price]] named Mount Hayes as one of four candidate mountain sites associated with an underground non-terrestrial base.

## Associated Incidents

- **1973 Stargate remote viewing.** Per [[OOr98r51Sj0]], Pat Price described Mount Hayes as concealing "a massive underground base with advanced technology, consoles, personnel that looked like military." Price named four mountain sites; Mount Hayes is the first.
- **Joe McMoneagle blind replication.** Years later, [[joe-mcmoneagle]] — given the same coordinates blind — saw the same mountain with the same underground command center; reported that the bases were "connected like nodes of a network."
