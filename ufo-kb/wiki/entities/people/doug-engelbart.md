# Doug Engelbart

Computer scientist (1925–2013) at SRI International. **Inventor of the computer mouse**; creator of the oN-Line System (NLS) — the first system to combine hypertext, collaborative real-time editing, and a graphical interface. Engelbart's 1968 "Mother of All Demos" demonstrated NLS live and introduced concepts that defined personal computing for the next 50 years.

**SRI / ARPANET / Vallée intersection**: Engelbart worked at SRI on the foundational ARPANET project during the 1970s — the precursor to the modern internet, funded by DARPA/ARPA. [[jacques-vallee]] was a researcher at SRI at the same time, initially doing computer science work (he computerized NASA's Mars map) before shifting fully into UFO research. The [[doe-secret-science-nexus]] framing in this KB notes that the same DARPA/SRI institutional network that funded Engelbart's networking work also funded Vallee's and Puthoff's parapsychology research, placing the origins of both the modern internet and serious government-sponsored UFO investigation in the same building at the same time.

If accurate, it places Lilly (cetacean communication researcher, LSD/ketamine consciousness explorer) alongside Engelbart in the ARPANET infrastructure layer.
