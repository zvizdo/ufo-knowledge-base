# 2020 Strait of Hormuz UAP D62

USCENTCOM 482 ATKS / 432 AEW ISR platform observed one UAP via FMV in the Strait of Hormuz / Gulf of Oman on 16 September 2020, after a mission marked by Iranian guard calls and two EMI events that caused flight path deviations.

## Key Facts

- **DTG**: 161732Z SEP 2020; observer FL180, 90 KIAS; MGRS 39RVM51
- **Platform**: 482 ATKS / 432 AEW, OKAS; ANDAS4 FMV
- **Prior EMI 1**: 1248Z–1259Z (11 min, COMPLETE, flight path deviation, JSIR 330412)
- **Prior EMI 2**: 1414Z–1441Z (27 min, COMPLETE, flight path deviation, JSIR 330414)
- **Iranian guard calls**: 3 calls (0408Z, 0421Z, 1141Z) — all prior to EMI and UAP
- **UAP description**: Absent from released document
- **Method**: FMV
