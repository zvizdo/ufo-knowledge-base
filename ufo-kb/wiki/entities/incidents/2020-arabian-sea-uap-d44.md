# 2020-arabian-sea-uap-d44

Round, cold-IR object tracked over the Arabian Sea on 15 Oct 2020 (daytime) by an O-2 pilot from 172 ATKS during an ISR mission. IR sensor set to black-hot; object appeared bright white. Slow WSW movement (~20 mph); ground range ~4.7 KM at sensor depression -50°.
