# Hughes Glomar Explorer

Purpose-built deep-sea recovery ship constructed for the **CIA's Project Azorian** (1968–1974) — the covert program to raise the wreck of the Soviet submarine **K-129** from over 16,000 feet in the Pacific. Operated commercially under [[global-marine-corporation]] cover (the "Hughes Mining Barge" / "manganese-nodule-mining" cover story) before partial declassification in the 2000s.

In UAP-adjacent discourse, Glomar Explorer is referenced as the **canonical proof-of-capability** that the US ran high-cost, high-secrecy ocean-recovery programs whose covers held for years. The same capability profile is invoked in [[uso-ocean-portals]] and adjacent thread discussions about whether similar programs might exist for unidentified-submerged-object recovery.

## Description

Custom-built recovery vessel; the famous "moon pool" hull cavity allowed components of the Soviet sub to be lifted from depth into the ship's interior under concealment.

## Provenance Chain

CIA → Global Marine Development cover → Hughes ownership cover → US Navy USNS designation post-program → eventual scrapping.

## Analysis / Findings

Glomar Explorer's documented existence is the single best-evidenced reference case for what a successful USO-recovery program *would look like* operationally — making it a structural anchor in the [[recurring-claims]] crash-retrieval cluster.
