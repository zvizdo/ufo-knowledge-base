# The Simulation Hypothesis

Book by [[riz-virk]] extending [[nick-bostrom]]'s simulation argument with empirical grounding from quantum physics, information theory, and video-game engineering. [[jacques-vallee]] wrote the foreword to the French edition ("he asked me to write the forward for the French version, which I did because by then I was hooked and I couldn't find a flaw in what he was saying").

## Key Arguments

1. **Quantum mechanics = game rendering**: superposition as lazy evaluation; wave function collapse as rendering trigger; the observer is the rendering engine.
2. **Nature's reusable code**: Fibonacci / golden ratio patterns in biology and cosmology as copied code modules; DNA base pairs as bits; electron/positron pairs as binary switches.
3. **Information Theory as simulation substrate**: [[john-wheeler]]'s "it from bit" is the physics foundation; reality arises from binary yes/no information.
4. **RPG vs. NPC**: the soul is a player porting into an avatar, not a locally generated NPC.

## Reception

Unusual for simulation-theory books in that it was endorsed by a serious empirical UFO researcher ([[jacques-vallee]]) rather than purely philosophical or pop-science audiences.
