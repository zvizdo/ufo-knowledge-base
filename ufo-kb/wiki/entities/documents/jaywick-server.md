# Jaywick Server

## Summary

Classified server used by the Pentagon for distributing intelligence-relevant technical documents. Access is granted to intelligence-officer personnel and aerospace contractors; not accessible to the general public. Identified by [[hal-puthoff|Hal Puthoff]] in [[Gf_tKn9TaP8]] as the platform where the [[dird-papers|38 AAWSAP DIRD papers]] were uploaded.

## Key Claims

### Sticky Popularity of the DIRD Set

Per Puthoff, document sets uploaded to Jaywick typically remain posted for "a little while, a month or so" and are then taken down. The DIRD set was an exception: every attempted takedown drew protest from readers, so the set stayed up indefinitely. This is evidence that a substantial cleared readership inside the IC and aerospace contractor community was actively engaged with the UAP-physics material, despite its formal cover story as 2050-horizon aerospace propulsion research.

Most of the DIRD set has subsequently been FOIA'd into the public domain — but the Jaywick history is itself a data point about the size and persistence of the cleared-side audience for UAP-adjacent physics research.

## Provenance

The name "Jaywick" surfaces in Puthoff's public account; the operational details (host agency, access controls, document retention policy) are not declassified. The system is described only in the context of the DIRD upload.
