# Mandela Effect

A phenomenon where large numbers of people share the same false memory — named for the widespread false belief that Nelson Mandela died in prison in the 1980s. In the UAP/UAP-adjacent KB it appears primarily as a [[simulation-theory]] data point: if consensus reality has "glitches" visible as shared misremembering, this suggests external modification of the timeline or simulation state.
