# Classification System

The US government's formal information security architecture, established by Executive Order (currently EO 13526, signed by Obama in 2009). The basic hierarchy:

- **Confidential** — disclosure could damage national security
- **Secret** — disclosure could cause serious damage
- **Top Secret** — disclosure could cause exceptionally grave damage
- **SCI (Sensitive Compartmented Information)** — requires TS clearance plus specific program read-in
- **SAP (Special Access Program)** — compartmented programs with access controlled by program manager
- **USAP (Unacknowledged SAP)** — program existence itself is classified; no acknowledgment to unauthorized personnel

**Above-TS tiers and UAP**: The SCI/SAP/USAP tiers are where UAP-related program claims concentrate. These tiers operate outside routine declassification review: EO 13526's 25-year automatic declassification rules do not apply to active SAPs. A USAP program can theoretically persist indefinitely without triggering any mandatory review.

**Relationship to compartmentalization**: The classification system defines the tiers; [[compartmentalization]] is the architecture by which information within those tiers is further subdivided by program and "need to know." An individual can hold TS/SCI clearance and still be excluded from any specific program compartment.

**KB relevance**: The claim that UAP programs escaped congressional oversight rests on understanding how the classification system's upper tiers (particularly USAP) operate — programs whose existence is not acknowledged cannot be reviewed by oversight personnel who lack awareness of them.
